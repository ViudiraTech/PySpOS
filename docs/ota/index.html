PySpOS 更新包

PySpOS 的 OTA 更新包。支持云端更新、本地安装，以及用 A/B 槽位回滚。

更新内容

  • apps 升级为真子进程 fork/exec，PID 0/1/2 引导与孤儿收养
  • 新增 11 步 OOBE 首次开机向导，真实时区（zoneinfo + TZ）与语言
  • EEVDF 调度器对标 Linux 6.6+，含 nice 权重表与信号状态机
  • 终端输入自愈：stty sane 恢复 + 输入归一化，修复按 Enter 刷 ^M
  • 修复子进程 stdio 中继协议不匹配导致输出丢失、后台作业挂死
  • 新增 SpaceConfig v2、命令注册表与 Tab 补全、真出厂重置
  • main.py 拆分为 src/shell/*，保留兼容 facade
  • 更新包补齐 requirements.txt / LICENSE / README.md
  • CI 改为分层节奏：日常单格，发版才跑全平台矩阵

安装前确认

Python3.10 或更高版本。云端抓取需要 requests 库。
系统Windows 7 及以上 / Linux / macOS。
磁盘至少 50 MB 可用空间。

更新出问题时回滚

回滚会切换到另一个槽位。请确认另一个槽位里有可用的系统版本，否则可能无法启动。

  1. 在 PySpOS 中输入 recovery，进入恢复模式。
  2. 在恢复模式中输入 ota_rollback。
  3. 确认回滚操作。
  4. 重启 PySpOS，使更改生效。

更新日志

这次改了什么

apps 升级为真子进程 fork/exec；11 步 OOBE 首次开机向导；EEVDF 调度器对标 Linux 6.6+；终端输入自愈；SpaceConfig v2 与命令注册表。完整条目见版本历史。

兼容性要求

装之前确认

  • Python

    3.10 或更高版本（云端抓取需要 requests 库）。

  • 系统

    Windows 7 及以上 / Linux / macOS。

  • 磁盘

    至少 50 MB 可用空间。

回滚指南

更新出问题时回滚

回滚会切换到另一个槽位，请确保另一个槽位有有效系统版本，否则可能无法启动。

  1. 在 PySpOS 中输入 recovery 进入恢复模式
  2. 在恢复模式中输入 ota_rollback
  3. 确认回滚操作
  4. 重启 PySpOS 以应用更改

PySpOS

用 Python 写的模拟操作系统。它跑在宿主系统上，自己实现了 shell、进程调度、文件系统、引导流程和 OTA 更新，也能执行 x86_64 的 ELF 程序。

概览

PySpOS 从 2022 年的“MP4 架构狗头 OS”一路改过来。现在的版本能跑命令、管理文件、执行 ELF 程序；应用是独立进程，调度器参照 Linux 的 EEVDF。

3.2.0 重构了内部结构：原先 1217 行的 main.py 拆成 src/shell/ 下的 sys、elf、ota、proc、dispatch 几个模块，原文件留作兼容层。调度在 process.py，进程引擎在 forkexec.py。

ELF 默认由 Unicorn Engine 执行真实的 x86_64 指令，系统调用转发给内置的模拟层。没装 unicorn 时退回自研的 SpaceCPU 1 Pro 模拟器，Windows 上也能跑。动态链接（INTERP）和 TLS 还没有实现。

3.2.0 的改动

  • 进程

    应用是独立的 OS 进程，不再是协作式模拟。PID 0（swapper）、1（init）、2（shell）依次引导；孤儿进程由 init 收养，退出后先成为僵尸，再被回收。

  • 调度

    EEVDF（Earliest Eligible Virtual Deadline First），参照 Linux 6.6+：nice 权重表、vruntime、虚拟截止期和信号状态机。

  • 后台作业

    cmd &、jobs、fg、bg、wait、$!，以及进程组与会话。前台交互经管道中继，后台作业的 stdin 接 /dev/null。

  • ELF 引擎

    默认用 Unicorn，没装就用 SpaceCPU 1 Pro。可以加 --stats、--map、--disasm、--strace 观察执行过程。

  • 窗口 API

    VortexGlass 管理窗口和输入。应用可以用 Python SDK 开多个窗口、处理键盘鼠标事件、绘制控件，或直接提交 RGBA 像素。记事本、文件浏览器和绘图程序各自持有界面和逻辑。API 与示例见 vortexglass.md。

  • 首次开机向导

    共 11 步的 curses 向导。语言和时区设置会实际生效（zoneinfo + TZ），完成标记写在 etc/.oobe_done，可以用 oobe 命令重跑。

  • 终端

    TUI 按显示宽度排版（CJK 双宽），并去掉完整的 ANSI 转义序列。输入侧有 stty sane 恢复、输入归一化和重试上限，按 Enter 出现 ^M 的问题已修复。

  • 命令

    命令走元数据注册表：分组 help、help <cmd>、Tab 补全，支持管道和重定向。PATH=apps/ 下的外部程序可以直接执行。

  • SpaceConfig v2

    .spc 配置格式，支持转义、行尾注释、null 和列表，带 Schema 校验，以及 spc_get / set / migrate 工具。

  • A/B 槽位与回滚

    更新装进非活动槽位，校验通过后再切换，失败可以回滚。OTA 云端已恢复（goutoustdio.rainyland.top），在 Recovery 里也可以从云端选版本装到指定槽位。

  • 出厂重置

    recovery.erase 清理 8 类数据，包括题库历史、shell 历史和整棵目录树的 __pycache__。

  • SPF 脚本

    SPF（Space Portable Format）是自研的脚本格式，支持变量、算术、输入和引入。

  • 许可与测试

    3.2.0 起使用 MIT 许可，代码在 ViudiraTech/PySpOS。回归测试在 GitHub Actions 上运行。

模块

每个模块只列一行，完整说明在仓库 README 和源码注释里。

模块文件作用
主循环src/kernel.py处理用户输入、执行命令、管理应用运行，启动时初始化各子系统。入口是 kernel.loop()。
SPF 解析src/parse_spf.py解析并执行 SPF 文件，支持 putchar() 与 exit() 系统调用。
OTA 更新src/ota.py版本检查、下载、验证、安装，云端地址是 goutoustdio.rainyland.top。
文件系统src/fs.pylist / create / read / delete 等文件操作 API，基于 os 和 shutil 实现。
配置管理src/btcfg.py管理启动配置（ROOT 权限、启动器锁定状态），存放在 etc/bootcfg.json。
ELF 运行src/elf_loader/ELF 加载、CPU 模拟和系统调用模拟，支持 x86 / x86_64。用法：run program.elf，可加 --stats / --map / --strace。

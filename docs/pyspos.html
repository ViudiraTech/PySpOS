PySpOS · Python 模拟操作系统

在用户态把一个操作系统实现一遍。

不是跑在裸机上的系统，而是在 Python 里模拟操作系统行为：能跑命令、管文件、执行 ELF 程序。目标是让人直接读源码、改源码，看清内核的每个决定是怎么做的。

介绍

从 2022 年的折腾到 v3.2.0

PySpOS 从 2022 年的“MP4 架构狗头 OS”一路迭代到现在：能跑命令、管文件、执行 ELF 程序，应用是独立进程，调度器对标 Linux。3.2.0 是一次内核级重构——1217 行的 main.py 拆成 src/shell/* 包（sys / elf / ota / proc / dispatch），原文件保留兼容 facade；调度在 process.py，进程引擎在 forkexec.py。

A/B 双槽位升级：更新装到非活动槽位，校验通过后切换，失败可回滚到上一个版本。命令走元数据注册表，提供分组 help、help <cmd>、Tab 补全，支持管道与重定向；PATH=apps/ 下的外部程序可直接执行，cmd & 后台作业配 jobs / fg / bg / wait。

ELF 执行默认由 Unicorn Engine 跑真实 x86_64 指令，syscall 转发到内置模拟层；缺 unicorn 时降级到自研 SpaceCPU 1 Pro 模拟器，Windows 也能跑。动态链接（INTERP）与 TLS 还在路线图上。

核心特性

应用从协作式模拟变成真子进程，调度器对标 Linux 6.6+，并第一次带上完整的首次开机向导。

  • 真子进程

    应用不再是模拟，而是独立 OS 进程。PID 0 swapper、1 init、2 shell 三级引导，孤儿被 init 收养，退出后回收为僵尸再清理。

  • EEVDF 调度

    Earliest Eligible Virtual Deadline First，对标 Linux 6.6+：nice 权重表、vruntime 推进、虚拟截止期与信号状态机。

  • Unicorn ELF 引擎

    默认执行真实 x86_64 指令，syscall 转发到模拟层；没装 unicorn 就降级到自研 SpaceCPU 1 Pro。支持 --stats / --map / --disasm / --strace 观测。

  • OOBE 首次开机向导

    11 步 curses 向导，语言与时区真实生效（zoneinfo + TZ），完成标记写入 etc/.oobe_done，可随时用 oobe 重跑。

  • 终端可靠性

    TUI 按显示宽度排版（CJK 双宽），剥离完整 ANSI 转义序列。stty sane 自愈 + 输入归一化 + 重试上限，按 Enter 刷 ^M 的问题不再出现。

  • 后台作业

    cmd &、jobs / fg / bg / wait、$!、进程组与会话。前台交互经管道中继，后台作业 stdin 接 /dev/null。

  • SpaceConfig v2

    .spc 格式：转义、行尾注释、null、列表类型，外加 Schema 校验与 spc_get / set / migrate 工具链。

  • 命令注册表

    元数据驱动的分组 help、help <cmd>、Tab 补全，以及 PATH=apps/ 外部命令解析。

  • A/B 槽位与回滚

    更新装到非活动槽位，校验通过后切换，失败可回滚。OTA 云端维护中，本地安装与回滚不受影响。

  • 真出厂重置

    recovery.erase 清理 8 类数据，含题库历史、shell 历史与全树 __pycache__。

  • SPF 脚本

    SPF（Space Portable Format）自研脚本格式，支持变量、算术、输入与引入。

  • MIT 开源

    3.2.0 起采用 MIT 协议。代码在 ViudiraTech/PySpOS，113 项测试由 GitHub Actions 把关。

技术细节

模块速览

每个模块一句话加一个入口，完整说明在仓库 README 与源码注释里。

  • 主循环 src/kernel.py

    处理用户输入、执行命令、管理应用运行，启动时初始化各子系统。

    kernel.loop()  # 主循环
  • SPF 解析 src/parse_spf.py

    SPF 文件格式的解析与执行，支持 putchar() 与 exit() 系统调用。

    putchar("Hello");  exit(0);
  • OTA 更新 src/ota.py

    版本检查、下载、验证、安装。云端维护中，默认关闭。

    compare_versions(v1, v2)  # 版本比较
  • 文件系统 src/fs.py

    list / create / read / delete 等文件操作 API，基于 os 与 shutil 实现。

    fs.create_file("test.txt", "content")
  • 配置管理 src/btcfg.py

    管理启动配置（ROOT 权限、启动器锁定状态），存放在 etc/bootcfg.json。

    btcfg.load_bootcfg()  # 加载配置
  • ELF 运行 src/elf_loader/

    整合 ELF 加载、CPU 模拟与系统调用模拟。支持 x86 / x86_64，模拟 Linux 系统调用。

    run program.elf  # 附 --stats / --map / --strace

项目介绍

什么是 PySpOS？

PySpOS 是用 Python 写的操作系统模拟器。不是真的操作系统，是在 Python 环境里模拟操作系统行为。目标是让人能直接读源码、改源码，看清一个内核的每个决定是怎么做出来的。

从 2022 年的「MP4 架构狗头 OS」一路迭代到现在的 v3.2.0：能跑命令、管文件、执行 ELF 程序，apps 是独立进程，调度器对标 Linux。

架构设计

3.2.0 起 1217 行的 main.py 拆成 src/shell/* 包（sys / elf / ota / proc / dispatch），原文件保留兼容 facade。调度在 process.py，进程引擎在 forkexec.py。

A/B 双槽位升级：更新装到非活动槽位，校验通过后切换，失败可回滚到上一个版本。

命令行界面

命令走元数据注册表，提供分组 help、help <cmd>、Tab 补全，支持管道与重定向；PATH=apps/ 下的外部程序可直接执行。支持 cmd & 后台作业与 jobs / fg / bg / wait。

ELF 程序执行

默认由 Unicorn Engine 执行真实 x86_64 指令，syscall 转发到内置模拟层；缺少 unicorn 时降级到自研的 SpaceCPU 1 Pro 模拟器。支持 --stats / --map / --disasm / --strace 观测。动态链接（INTERP）与 TLS 尚在路线图上。

核心特性

3.2.0 是一次内核级重构：apps 从协作式模拟变成真子进程， 调度器对标 Linux 6.6+，并首次带上了完整的首次开机向导。

真子进程

apps 不再是模拟，而是独立 OS 进程。PID 0 swapper、1 init、2 shell 三级引导，孤儿被 init 收养、退出后回收为僵尸再清理。

EEVDF 调度

Earliest Eligible Virtual Deadline First，对标 Linux 6.6+： nice 权重表、vruntime 推进、虚拟截止期与信号状态机。

Unicorn ELF

默认由 Unicorn Engine 执行真实 x86_64 指令，syscall 转发到模拟层； 没装 unicorn 就降级到自研 SpaceCPU 1 Pro。Windows 也能跑。

OOBE 首次开机

11 步 curses 向导，语言与时区真实生效（zoneinfo + TZ）， 完成标记写入 etc/.oobe_done，可随时用 oobe 重跑。

终端可靠性

TUI 按显示宽度排版（CJK 双宽），剥离完整 ANSI 转义序列。 stty sane 自愈 + 输入归一化 + 重试上限—— 按 Enter 疯狂刷 ^M 的问题不会再出现。

后台作业

cmd &、jobs / fg / bg / wait、$!、进程组与会话。前台交互经裸管道中继， 后台作业 stdin 接 /dev/null。

SpaceConfig v2

.spc 格式：转义、行尾注释、null、列表类型， 外加 Schema 校验与 spc_get/set/migrate 工具链。

命令注册表

元数据驱动的分组 help、help <cmd>、Tab 补全， 以及 PATH=apps/ 外部命令解析。

A/B 槽位与回滚

更新装到非活动槽位，校验通过后切换，失败可回滚。 OTA 云端维护中（src/pyspos.py: OTA_ENABLED）， 本地安装与回滚不受影响。

真出厂重置

recovery.erase 清理 8 类数据，含题库历史、shell 历史 与全树 __pycache__。

SPF 脚本

SPF（Space Portable Format）自研脚本格式，支持变量、算术、 输入与引入。

MIT 开源

3.2.0 起采用 MIT 协议。代码在 ViudiraTech/PySpOS， 113 项测试由 GitHub Actions 把关。

技术细节

内核模块

kernel.py 是 PySpOS 的主内核，负责处理用户输入、执行命令、管理应用运行。内核启动时显示 ASCII 艺术 Logo，初始化各子系统。

kernel.loop()  # 主循环，处理用户输入

SPF 解析器

parse_spf.py 实现 SPF 文件格式的解析和执行。支持 putchar() 和 exit() 系统调用，适合编写简单的演示程序。

putchar("Hello");  exit(0);

OTA 更新

ota.py 处理 OTA 更新逻辑，包括版本检查、下载、验证、安装。支持从 https://pyspos.us.ci/ota/ 获取更新。

compare_versions(v1, v2)  # 版本比较

文件系统

fs.py 提供文件系统操作 API，包括 list_dir、create_file、read_file、delete_file 等。基于 Python 的 os 和 shutil 模块实现。

fs.create_file("test.txt", "content")

配置管理

btcfg.py 管理启动配置，包括 ROOT 权限、启动器锁定状态等。配置文件存储在 etc/bootcfg.json。

btcfg.load_bootcfg()  # 加载配置

应用系统

apps 目录包含系统应用，如 calc.py（计算器）、hello.py（示例程序）等。通过 open 命令运行应用。

open hello  # 运行 hello.py

ELF 运行器

elf_runner.py 整合 ELF 加载器、CPU 模拟器和系统调用模拟器，提供完整的 ELF 程序执行功能。支持 x86/x86_64 架构，模拟 Linux 系统调用。

run_elf("program.elf")  # 运行 ELF 程序

兼容性要求

Windows

Windows 7 及以上版本，推荐使用 Windows 以获得最佳兼容性

Linux

主流发行版，如 Ubuntu、Debian、Fedora 等

macOS

macOS 10.14 及以上版本

Python

Python 3.7 或更高版本，需要安装 requests 库

测试须知

下载前，请先读完这份说明

这是一份公开测试镜像，不是稳定发行版。启动之前先确认环境，准备好记录和反馈，再把它当成实验对象，而不是日常系统。

重要：请勿在重要数据或主力设备上直接测试

当前 NTFS 写入驱动尚未被认为可以信任，真实 GPU 驱动、虚拟化设备和 Linux ABI 也没有全部完成。请使用虚拟机、备用设备或可抛弃磁盘，并提前备份所有数据。每次测试请使用本页面的当前镜像，不要混用旧镜像或第三方重打包文件。

运行前确认

基础门槛
  • 处理器：x86_64；512 MB 内存可启动，运行图形桌面建议 1 GB 以上并配置 swap。
  • 固件：通过 Limine 引导，UEFI 已验证，Legacy 模式也受支持。
  • 已验证环境：QEMU/KVM Q35，以及 Dell PowerEdge R410 等实体服务器。
  • 网卡：Intel e1000/e1000e 或 Realtek RTL8139/8169；其他网卡可能无法联网。
  • 存储：支持 IDE/ATA、AHCI、NVMe 和 USB Mass Storage；默认根文件系统为 tmpfs。

建议：先从虚拟机开始，不要使用 NTFS 重要分区。

推荐启动步骤

虚拟机优先
  1. 1. 校验文件：Linux/macOS 使用 sha256sum Uinxed-x64-slim.iso；Windows PowerShell 使用 Get-FileHash .\Uinxed-x64-slim.iso -Algorithm SHA256。
  2. 2. 准备虚拟机：将 ISO 挂载为光盘或启动介质，优先选择 UEFI，建议分配至少 1 GB 内存。
  3. 3. 准备实体机：只接入备用磁盘或测试用 USB，先备份；不要对不确定的设备路径执行写盘命令。
  4. 4. 记录过程：从 Limine、内核、用户态到桌面的每一阶段都记下结果；若屏幕没有输出，可尝试串口 ttyS0 获取日志。

已知限制

体验版边界
  • 真实 GPU 驱动、虚拟化设备和音频支持仍未全部完成。
  • Linux ABI 仍有缺口；systemd 目前只是初步跑通，不是生产可用状态。
  • PS/2 输入、evdev 消费者、poll/epoll 唤醒与 EEVDF 调度器仍在验证。
  • 本镜像为 slim 版，部分 Linux 应用已精简移除；缺少某个应用属于镜像预期范围。
  • NTFS 写入尤其谨慎，不要用它保存唯一副本或重要工作资料。

如何反馈

共同完善

请尽量做到“一个问题一条反馈”，并注明它是始终发生、偶尔发生，还是只在某个环境触发。请附上：

  • 机器型号、CPU、内存、显卡与网卡，或虚拟机版本和固件模式。
  • 启动阶段、最小复现步骤、预期结果与实际结果。
  • 发生频率、临时绕过方法，以及串口/屏幕日志和截图。

请将内容发送到 goutoustdio@outlook.com，或提交到 ViudiraTech/PySpOS。发送前请移除个人数据。

建议测试清单

从启动到稳定性，逐项留下结果

不需要一次做完所有项目；优先记录能复现、能描述清楚的启动、硬件和应用问题。

启动链路

Limine · UEFI / Legacy
确认能看到启动画面，并分别记录 UEFI 与 Legacy（如果你的设备支持）的结果；启动失败时优先保留串口日志。

桌面与输入

键盘 · 鼠标 · 显示
测试 PS/2、USB HID、窗口显示、鼠标移动与点击；虚拟机可额外观察 VirtIO-GPU 路径，实体机则记录显卡型号。

网络

DHCP · IPv4 / IPv6
确认网卡是否被识别、是否能通过 DHCP 获取地址，以及断开/重连后网络能否恢复。非 e1000/e1000e 或 RTL8139/8169 网卡请单独标注。

存储与文件

只用测试盘
在临时卷上测试读写、重启后的数据保持和文件系统挂载；不要用重要 NTFS 分区验证写驱动。

应用兼容性

按镜像实际内容测试
如果镜像包含对应应用，可测试终端、OpenJDK、DOOM 或其他 Linux 软件；应用缺失、启动失败和运行崩溃请分别记录。

稳定性

重启 · 关机 · 异常退出
至少完成一次正常重启和关机；若发生卡死、崩溃或无法再次启动，请保留现场信息和复现步骤。

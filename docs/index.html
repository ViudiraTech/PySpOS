01 / INPUT

先理解，你想做什么。

Shell 将输入解析成命令与参数，再交给对应的处理模块。管道、重定向和后台作业，从这里开始。

src/shell/dispatch.py查看 Shell 模块 ↗
02 / PROCESS

给程序，一个独立的进程。

外部应用通过 fork / exec 运行。进程有自己的身份与生命周期，调度器用虚拟运行时间和截止期安排执行。

src/forkexec.py · src/process.py了解进程与调度 ↗
03 / EXECUTION

指令运行，系统开始回应。

ELF 程序由 Unicorn 执行 x86_64 指令；系统调用转发到模拟层。你可以观察执行、修改实现，再运行一次。

Unicorn Engine → syscall探索 ELF 执行引擎 ↗
Python / 用户态模拟

PySpOS.

让系统原理，
成为可执行的代码。

维护中 v3.2.0 RC1 · MIT

阅读项目介绍 ↗下载与更新 ↗

一个可以运行，也可以逐行理解的模拟操作系统。

在 Python 中实现进程调度、内存映射、文件系统和引导流程。应用运行在真实子进程中，ELF 由 Unicorn 执行 x86 指令；改动源码后，你可以直接观察系统行为的变化。

调度
EEVDF 虚拟截止期与 nice 权重
进程
真实 fork / exec、作业控制与信号
引导
OOBE、A/B 槽位与签名验证
从这里开始 / Python 3.10+
$ git clone https://github.com/ViudiraTech/PySpOS.git
$ cd PySpOS
$ pip install -r requirements.txt
$ python launcher.py

在真实硬件上，让自己写的内核接管系统。

基于 Uinxed 自研 UNIX-like 内核，配一整套自研用户态。从窗口合成器到浏览器，一层一层实现。内核已在实体服务器上跑通，OpenJDK 与 DOOM 已能运行，图形与部分 ABI 仍在补齐。

兼容

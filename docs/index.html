PySpOS

Python 模拟操作系统
持续维护

在用户态把进程调度、内存映射、文件系统和引导流程实现一遍。 3.2.0 起 apps 是真子进程，调度器对标 Linux 6.6+ 的 EEVDF， ELF 由 Unicorn 执行真 x86 指令。

  • EEVDF 调度器 + PID 0/1/2 引导与孤儿收养
  • 11 步 curses 首次开机向导（OOBE），真实时区与语言
  • Unicorn ELF 引擎，Windows 也能跑

我们怎么做事

技术取向

这些原则贯穿 PySpOS 与 SpaceOS 系列：先做对，再做快。

对标真实内核

调度器照着 Linux 6.6+ 的 EEVDF 实现，nice 权重表、虚拟运行时间与 虚拟截止期一个不省。我们想让人读源码时看到的和读 Linux 一样。

权限分层

Ring 0-3 分层权限管理，配合自研文件系统与安全引导； 特权操作一律走 syscall RPC，不让子进程直接碰父进程内存。

模块化

清晰的文件与接口边界，命令走元数据注册表， 3.2.0 把 1217 行的 main.py 拆成了 src/shell/*。

开源

核心代码全部在 GitHub 公开，MIT 协议。 包括那些写砸了又重写的部分。

自己写底层

SPF 脚本格式、SPFS 文件系统、curses 布局引擎， 都是为了让「原理看得见」而自己写的。

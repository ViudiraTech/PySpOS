几个学生，
在写操作系统。

GoutouStdio 是学生自发组织的开源小组，2022 年开始做操作系统。现在维护两个项目：用 Python 写的 PySpOS，和用 Rust 写内核的 SpaceOS 9。

了解 PySpOS 了解 SpaceOS 9

项目

PySpOS

维护中 v3.2.0 RC1 · MIT

用 Python 写的模拟操作系统。有进程调度、文件系统和引导流程，能执行 x86_64 的 ELF 程序。

介绍下载

SpaceOS 9

公开预览 x86_64

内核 SpaceKernel 3.0 用 Rust 写成，实现 Linux ABI。自带 PID 1（systemg）和 C 库（splibc），能运行动态链接的 BusyBox。

介绍下载镜像

SpaceOS 8

抢先体验 x86_64 · Apache-2.0

上一代项目。基于 Uinxed 内核（C 写的 UNIX-like 内核），带自研桌面 SPUI 和一批系统程序。

介绍下载镜像

存档

  • SpaceOS 7

    已停更 完全自研的混合内核，2026 年启动，做到约一半。

  • SpaceOS 6

    已停更 基于 Uinxed-Kernel 的桌面系统，带 SPUI 1.0，2024 年发布。

运行 PySpOS

需要 Python 3.10 或更高版本。

git clone https://github.com/ViudiraTech/PySpOS.git
cd PySpOS
pip install -r requirements.txt
python launcher.py

各平台的要求见配置要求，功能和模块见 PySpOS 介绍。

历史

  • 2022

    工作室成立。从网上的“狗头 OS”项目开始，做“MP4 架构”的实验，有了第一批关注者。

  • 2023

    开始读别人的代码，认识了原作者，互相交流。

  • 2024

    基于 ViudiraTech 的 VimdropOS 做出第一版 SpaceOS。

  • 2025

    深入研究 UEFI，基于 Uinxed-Kernel 开发正式的 SpaceOS。

  • 2026

    UEFI 研究完成后尝试全部自研（SpaceOS 7），做到一半停下；之后回到内核与桌面，做出 SpaceOS 8。10 月公开 SpaceOS 9 预览，内核换成 Rust 写的 SpaceKernel 3.0。

SpaceOS 7

尝试完全自研的混合内核操作系统：不依赖外部代码，UEFI 引导和内核加载都自己写。做到约一半后停止。

启动
2026
方式
完全自研
进度
约 50%

这个项目已停止开发，本页仅作存档

不再维护，不接受 issue、功能请求或移植，请不要基于它继续投入。目前在维护的是 PySpOS 和 SpaceOS 9；PySpOS 的代码在 ViudiraTech/PySpOS。

背景

2026 年，团队研究清楚 UEFI 之后启动了这个项目：没有外部代码，没有依赖，UEFI 引导和内核加载全部自己写。设计目标写的是“完全自研、混合内核、极致性能”，混合内核想兼顾微内核的稳定和宏内核的性能。

做到约一半时停止：用户态没做完，还存在 Heisenbug。中间重构过一次引导和内核；桌面环境运行在 Ring 3，桌面崩溃不会拖垮内核。

做到的部分

  • SPFS 2.0 Ultra

    自研文件系统，带 Journal 日志、CRC64 数据校验和缓存块机制。

  • 内核重构

    引导程序自己写（没用 Limine / GRUB）；放弃 Uinxed-Kernel，改为纯自研；伙伴系统加 Slab 分配器；进程间 IPC 和用户态支持。

  • Ring 3 桌面

    桌面跑在用户空间，与内核隔离，桌面崩溃不影响内核。

  • SMP 多核

    多核调度、同步机制、内存管理和中断处理。

  • xHCI 控制器

    xHCI 驱动，支持 USB 3.0 及以上，向后兼容 USB 2.0。

  • 空间 API

    自研的系统调用接口，包含系统调用、IPC 和权限控制。

内核设计

  • 混合内核

    微内核组件放到用户空间，关键服务留在内核空间；有 IPC 和权限管理。

  • UEFI 库

    从零写的 UEFI 库，高半地址内核加载，不依赖外部引导代码。

  • 内存管理

    Buddy System 加 Slab 分配器，4 KB 与 2 MB 大页，虚拟内存和硬件辅助的内存保护。

  • 进程调度

    CFS 完全公平调度，支持实时调度、多核负载均衡与节能调度。

  • 设备驱动

    存储（IDE / AHCI / NVMe / USB / SCSI）、显示、网络、音频、输入，以及 xHCI USB 驱动。

进展

  1. 搞懂 UEFI

    理解 UEFI 之后，启动完全自研的操作系统项目。（用户态没做好）

  2. 混合内核设计

    完成混合内核的架构设计。

  3. 内核实现

    完成内核基本功能：进程调度、内存管理、中断处理。

  4. Ring 3 桌面

    实现用户空间的桌面环境。

SpaceOS 7

纯自研混合内核架构操作系统的尝试：不依赖外部代码，UEFI 引导与内核加载全部自己写。项目做到约一半后停止。

启动 · 2026 完全自研 进度约 50%
!

该路线已停止开发，本页仅作历史存档

不再维护，不再接受 issue、功能请求或移植。请勿基于它继续投入。当前唯一在维护的产物是 PySpOS，代码已迁移至 ViudiraTech/PySpOS。

介绍

掌握 UEFI 之后的一次从零开始

2026 年，团队完全掌握 UEFI 技术之后启动了这个自研项目：没有外部代码，没有依赖，UEFI 引导、内核加载全部自己写。设计理念是“完全自研、混合内核、极致性能”——混合内核结合微内核和宏内核的优点，既保证稳定性，又提供高性能。

做到约一半时停止：用户态没做完，存在 Heisenbug。中间引导和内核完全重构，桌面环境运行在 Ring 3——桌面崩了内核不会跟着炸。

特性

做到一半的东西

  • SPFS 2.0 Ultra 文件系统

    自研旗舰文件系统：Journal 日志、CRC64 数据校验、缓存块机制，原生内置。

    • Journal 日志功能
    • CRC64 数据校验
    • 缓存块机制
  • 内核重构

    中间引导和内核全部手搓：自研引导程序（没用 Limine / GRUB），抛弃 Uinxed-Kernel 转纯自研，伙伴系统 + Slab 分配器，进程间 IPC 与用户态支持。

  • Ring 3 桌面环境

    桌面跑在用户空间，内核与用户空间隔离，桌面崩溃不影响内核，安全性更高。

  • SMP 多核

    对称多处理支持：多核调度、同步机制、内存管理与中断处理。

  • xHCI 控制器

    完整的 xHCI 驱动，USB 3.0 及以上，向后兼容 USB 2.0，多设备与高带宽传输。

  • 空间 API

    自研系统调用接口：丰富的系统调用、高性能 IPC、灵活通信机制与权限控制。

技术细节

内核侧的设计

  • 混合内核架构

    微内核组件用户空间化，关键服务跑在内核空间，高效 IPC 与完善的权限管理。

  • 纯手写 UEFI 库

    从零构建 UEFI 库，高半地址内核加载，不依赖任何外部引导代码。

  • 内存管理

    伙伴系统（Buddy System）+ Slab 分配器，4KB 与 2MB 大页，完整虚拟内存与硬件辅助内存保护。

  • 进程调度

    CFS 完全公平调度，实时调度支持，多核负载均衡与节能调度。

  • 设备驱动

    存储（IDE / AHCI / NVMe / USB / SCSI）、显示、网络、音频、输入，以及 xHCI USB 驱动。

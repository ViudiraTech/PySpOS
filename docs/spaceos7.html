这个项目已停止开发，本页仅作存档

不再维护，不接受 issue 或功能请求。目前在维护的是 PySpOS 和 SpaceOS 9。

背景

2026 年搞懂 UEFI 后启动：不用外部代码，引导和内核加载全部自己写。目标是混合内核，兼顾微内核的稳定和宏内核的性能。

做到约一半时停止：用户态没完成，还有难以复现的 Heisenbug。

做到的部分

  • 自写引导：没用 Limine 或 GRUB，也不再基于 Uinxed-Kernel。
  • 混合内核：微内核组件放在用户空间，关键服务留在内核，带 IPC 和权限控制。
  • 内存：Buddy + Slab 分配器，4 KB 与 2 MB 页。
  • 调度：CFS，支持实时调度和多核负载均衡。
  • Ring 3 桌面：桌面跑在用户空间，崩溃不影响内核。
  • SPFS 2.0 Ultra：自研文件系统，带日志和 CRC64 校验。
  • 驱动：xHCI（USB 3.0+）、存储、显示、网络、音频和输入。
  • 空间 API：自研的系统调用、IPC 和权限接口。

进展

  1. 搞懂 UEFI，启动项目。
  2. 完成混合内核的架构设计。
  3. 实现调度、内存管理和中断处理。
  4. 实现 Ring 3 桌面，之后停止。

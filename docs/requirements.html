PySpOS 3.2.0

纯用户态程序，能跑 Python 就能跑。

项目最低配置推荐配置
Python3.103.12 或 3.14（CI 测过的版本）
系统Windows 7、主流 Linux、macOS 10.14同左
处理器双核同左
内存512 MB同左
存储120 MB 可用空间同左
终端80×24 字符同左
可选依赖无unicorn（ELF 引擎）、tzdata（真实时区）

不需要管理员权限和独立显卡。缺 unicorn 时退回自研模拟器，Windows 和精简容器镜像需要 tzdata 才有真实时区。

SpaceOS 9 公开预览

目前只在 QEMU 上验证过。

项目最低配置推荐配置
平台x86_64 QEMUx86_64 QEMU，Q35 机型
固件OVMF（UEFI）同左
内存512 MiB同左
显示—VirtIO GPU 2D

真实硬件、GPU、音频、网络和睡眠唤醒都没有验证。aarch64 / riscv64 只通过编译检查，镜像里没有它们的用户态。启动命令见下载页。

SpaceOS 8

请用可抛弃的机器和测试盘

NTFS 写入驱动还不能信任，不要让它碰重要数据。

项目最低配置推荐配置
处理器x86_64x86_64 多核（支持 SMP）
内存128 MB1 GB 以上（图形桌面 + swap）
固件UEFI 或 Legacy BIOSUEFI（已验证）
显示GOP 帧缓冲VirtIO-GPU；真实显卡驱动未完成
存储不需要（默认根是 tmpfs）IDE / AHCI / NVMe / USB 存储
输入PS/2 键盘和鼠标USB 键盘和鼠标（xHCI，已验证）
网络可以不接Intel e1000 / e1000e 或 Realtek RTL8139 / RTL8169
音频可以没有Intel HD Audio

VirtIO 和 SB16 声卡默认关闭，要用 make menuconfig 打开。实体机已在 Dell PowerEdge R410 上验证。构建依赖见 SpaceOS 8 介绍。

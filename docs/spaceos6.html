背景

SpaceOS 6 基于 ViudiraTech 开发的 Uinxed-Kernel 深度定制，2024 年开始研发，内核优化、用户界面、文件系统和硬件驱动都是自己做的。

Uinxed-Kernel 是 64 位宏内核，运行在 CPU Ring 0，进程调度、内存管理、文件系统和设备驱动都在内核空间。SPUI（SpaceOS User Interface）1.0 是自研的桌面环境。硬件上支持 AHCI / NVMe 存储、SB16 声卡、JPG 硬件加速和分区表，可以多系统部署。

做到的部分

  • SPUI 1.0 桌面

    自研桌面环境，支持窗口管理、任务栏和开始菜单。

  • SPF Parser 2.0

    解析并执行 SPF（SpaceOS Format）可执行文件。2.0 版性能更好，支持更多系统调用。

  • JPG 图片解析

    原生支持 JPG 解析与显示，不依赖第三方库。

  • SB16 声卡

    SB16 声卡驱动，支持 PCM 播放和 MIDI 合成。

  • 分区表与存储

    分区表、AHCI、NVMe，多分区管理和引导加载器配置。

  • SPFS 2.0

    自研文件系统，带文件权限管理和日志，面向硬盘优化读写延迟和吞吐。

内核与子系统

  • Uinxed-Kernel

    ViudiraTech 开发的 64 位宏内核，运行在 Ring 0，提供系统调用、进程调度、内存管理和文件系统。

  • 宏内核架构

    进程管理、内存管理、文件系统和设备驱动都在内核空间。

  • 内存管理

    分页和内存保护。

  • 存储

    IDE / AHCI / NVMe 接口，MBR 与 GPT 分区表。

  • 音频

    SB16 兼容驱动，DMA 传输，音频混合与音量控制。

  • 当年的配置要求

    x86 处理器（Pentium 及以上），内存最低 64 MB（推荐 128 MB 以上），至少 500 MB 可用空间，VESA 兼容显卡（800×600）。

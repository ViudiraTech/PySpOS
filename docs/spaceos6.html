背景

2024 年开始，在 ViudiraTech 的 Uinxed-Kernel 上深度定制。界面、文件系统和驱动是自己做的。

做到的部分

  • SPUI 1.0：自研桌面，有窗口管理、任务栏和开始菜单。
  • SPF Parser 2.0：执行 SPF 可执行文件，支持更多系统调用。
  • SPFS 2.0：自研文件系统，带权限管理和日志。
  • 存储：IDE / AHCI / NVMe，MBR 与 GPT 分区表，可以多系统部署。
  • 音频：SB16 驱动，支持 PCM 播放和 MIDI。
  • 图片：原生 JPG 解析，不依赖第三方库。

内核

Uinxed-Kernel 是 64 位宏内核，运行在 Ring 0。调度、内存、文件系统和驱动都在内核空间，内存有分页和保护。

当年的配置要求

  • Pentium 及以上的 x86 处理器。
  • 内存 64 MB，推荐 128 MB 以上。
  • 500 MB 可用空间。
  • VESA 兼容显卡，800×600。

介绍

基于 Uinxed-Kernel 的定制桌面系统

SpaceOS 6 是基于 Uinxed-Kernel（ViudiraTech 开发）深度定制的桌面操作系统。2024 年开始研发，内核优化、用户界面、文件系统、硬件驱动都是自己做的。

Uinxed-Kernel 是 64 位宏内核，运行在 CPU Ring 0，提供进程调度、内存管理、文件系统与设备驱动，所有核心组件都在内核空间。SPUI（SpaceOS User Interface）1.0 是自研桌面环境，界面简洁，适合日常办公和娱乐。硬件上支持 AHCI / NVMe 存储、SB16 声卡、JPG 硬件加速与分区表，可多系统部署。

特性

当时做到的部分

  • SPUI 1.0 桌面

    自研桌面环境，支持窗口管理、任务栏与开始菜单。

  • SPF Parser 2.0

    SPF（SpaceOS Format）可执行文件解析与执行，2.0 版带来更好的性能与更多系统调用支持。

  • JPG 图片解析

    原生支持 JPG 解析与显示，无需第三方库，支持多种尺寸与压缩质量。

  • SB16 声卡

    完整 SB16 支持，高质量音频输出，PCM 播放与 MIDI 合成。

  • 分区表与存储

    分区表、AHCI、NVMe，多分区管理与引导加载器配置。

  • SPFS 2.0 文件系统

    自研高性能文件系统，文件权限管理与日志功能，为硬盘存储优化的低延迟、高吞吐读写。

技术规格

内核与子系统

  • Uinxed-Kernel

    ViudiraTech 开发的 64 位宏内核，Ring 0 最高特权级，完整的系统调用、进程调度、内存管理与文件系统支持。

  • 宏内核架构

    进程管理、内存管理、文件系统、设备驱动全部在内核空间，高效的系统性能与低延迟硬件访问。

  • 内存管理

    分页内存管理与内存保护，优化的分配算法，减少碎片化。

  • 存储

    IDE / AHCI / NVMe 接口，MBR 与 GPT 分区表。

  • 音频

    SB16 兼容驱动，DMA 传输，音频混合与音量控制。

  • 当年要求的配置

    x86 处理器（Pentium 及以上），内存最低 64 MB（推荐 128 MB+），至少 500 MB 可用空间，VESA 兼容显卡（800×600）。

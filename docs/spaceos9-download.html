校验

下载后先核对 SHA-256，再启动。校验命令二选一：

sha256sum SpaceOS-9-x86_64.iso
Get-FileHash .\SpaceOS-9-x86_64.iso -Algorithm SHA256

也可以下载 SHA-256 校验文件。

在 QEMU / UEFI 上启动

需要 x86_64 QEMU、OVMF UEFI 固件和至少 512 MiB 内存。推荐 Q35 机型和 VirtIO GPU 2D。Linux 主机上的命令示例：

qemu-system-x86_64 -machine q35 -m 512 -smp 4 \
  -drive if=pflash,format=raw,readonly=on,file=/usr/share/OVMF/OVMF_CODE_4M.fd \
  -device virtio-gpu-pci -cdrom SpaceOS-9-x86_64.iso

建议用图形窗口；串口控制台也可以，加 -serial stdio。

启动后 systemg 会拉起 console shell。看到 / # 后可以执行 uname -a、id、nproc、ls、cat /etc/os-release。退出 shell 后，systemg 会重新拉起它。

已知限制：真实 GPU、音频、网络和部分 Linux ABI 还在做；aarch64 / riscv64 的用户态不在这个镜像里。

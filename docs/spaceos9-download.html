启动方式

在 QEMU / UEFI 上启动

需要 x86_64 QEMU、OVMF UEFI 固件和至少 512 MiB 内存。推荐 Q35 机型与 VirtIO GPU 2D。

  • QEMU 命令 Linux 主机示例
    qemu-system-x86_64 -machine q35 -m 512 -smp 4 \
  -drive if=pflash,format=raw,readonly=on,file=/usr/share/OVMF/OVMF_CODE_4M.fd \
  -device virtio-gpu-pci -cdrom SpaceOS-9-x86_64.iso

    建议使用图形窗口；串口控制台也可用 -serial stdio。

  • 启动后 交互验证

    systemg 会启动 console shell。看到 / # 后可执行 uname -a、id、nproc、ls、cat /etc/os-release。退出 shell 会由 systemg 重新拉起。

  • 已知边界 诚实标注

    真实 GPU、音频、网络与部分 Linux ABI 仍在推进；aarch64/riscv64 用户态未包含在此镜像中。
